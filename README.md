# React Firebase Login

A responsive login page built with React, Vite, TypeScript, and Material UI. It includes email validation and Google Sign-In using Firebase Authentication.

## Features

- Responsive login design
- Email and password validation
- Google Sign-In with Firebase
- Displays the user's access token after login
- Firebase Hosting deployment

## Tech Stack

- React
- Vite
- TypeScript
- Material UI
- Firebase Authentication
- Firebase Hosting

## Getting Started

Clone the repository and install the dependencies:

```bash
git clone <repository-url>
cd react-firebase-login
npm install
```

Create a `.env` file and add your Firebase configuration.

Start the development server:

```bash
npm run dev
```

## Build

```bash
npm run build
```
